The rules stay consistent in every direction.

01 / One visual language

One accent, semantic color tokens, one icon family, and one shared component set across every route.

02 / Predictable hierarchy

One page title, one primary action, stable navigation. Finding knowledge comes before credits and upgrades.

03 / A deliberate spacing scale

Use a 4px base. Controls, cards, dialogs, and page gutters follow the same rhythm.

04 / Readable by default

16px app body, 14px secondary text, 12px metadata. WCAG AA contrast and visible keyboard focus.

05 / Complete interaction states

Design loading, empty, error, disabled, selected, and success states alongside the happy path.

06 / Mobile is designed

44px touch targets, stacked content, a navigation drawer, and actions that never depend on hover.
